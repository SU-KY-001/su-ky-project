## 1. Bảng màu chính

### Màu thương hiệu và nền


| Token          | Mã        | Dùng cho                                                                             |
| -------------- | --------- | ------------------------------------------------------------------------------------ |
| `--paper`      | `#F4ECDC` | Nền trang chính (giấy dó)                                                            |
| `--paper-deep` | `#E9DCC2` | Nền section xen kẽ, thẻ, panel                                                       |
| `--night`      | `#14110F` | Nền hero, header khi trên hero, chế độ ngôi nhân vật                                 |
| `--ink`        | `#1C1714` | Chữ chính trên nền giấy                                                              |
| `--ink-soft`   | `#5B4E44` | Chữ phụ, mô tả, meta                                                                 |
| `--vermilion`  | `#B8322A` | Màu nhấn chính: nút chính (CTA), node đang chọn, tiến trình, lời thoại ngôi nhân vật |
| `--bronze`     | `#B58A3C` | Viền mảnh, node có nội dung, divider, icon điểm nhấn                                 |
