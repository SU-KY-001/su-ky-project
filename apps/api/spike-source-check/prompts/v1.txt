PROCEDURE (follow in order for EVERY block that states a fact)
1. Skip a block only if it contains no checkable fact (no person, place, year, number, event). Feelings, transitions and rhetoric are not checked.
2. List the slots of each fact: WHO, WHAT, WHERE, WHEN, HOW MANY. Example: "Lý Thường Kiệt đánh quân Tống trên sông Bạch Đằng" = who: Lý Thường Kiệt, what: defeated Tống army, where: sông Bạch Đằng.
3. search_source with 2-4 distinctive words (names, year). Diacritics are ignored. At most 2 searches per block; then read_pages on the best page. You MUST read_pages every page you will cite.
4. Compare EVERY slot with the page text. If ANY slot differs from the page (other person, other place, other year, other number), that is CONTRADICTED. Do not excuse a different place or number as "close enough". Different spelling or name order of the same person is not a difference.
5. If the page agrees on all slots, report nothing for that block.
6. If after two searches and a read you found nothing relevant, report basis=NOT_FOUND (severity LOW, evidence []). This does NOT mean the claim is false.

EVIDENCE RULES (a program checks them)
- evidence.quote = ONE contiguous sentence or clause, at most 30 words, copied character by character from the read_pages output of that page. Never use "..." or "…", never join two passages, never rephrase, never add or drop words.
- The source text contains page markers like [19b]. If one lies inside your quote, copy it too; better, choose a quote that does not contain one.
- Pick the quote that shows the differing slot (e.g. the sentence naming the real place or number).
- Never cite a page you did not open with read_pages. Never invent a page or a quote.

FIELDS
- severity: HIGH = a slot clearly differs; MEDIUM = differs by a small amount or the source itself is ambiguous; LOW = only NOT_FOUND.
- suggestion: the whole block rewritten with the corrected fact, only when the page gives the corrected value; otherwise null.
- message: Vietnamese, one or two short sentences, soft wording ("nguồn ghi ... AI nghi ngờ, chưa xác minh"), mention the page. Never state "sai" as a certain fact.
- blockRef: exactly the ref of the block.
