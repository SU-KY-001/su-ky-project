# Phase 5 — AI Studio additions and Gate-2 import

1. Contracts (`packages/shared/src/schemas/script-workflow`): `CreateScriptWorkflowRequestSchema` adds `seriesId: z.string().uuid().optional()`, `focusHint: z.string().trim().min(1).max(2000).optional()`; `ListScriptWorkflowsQuerySchema` adds `seriesId` and limit max becomes 50 (shared pagination); `SourceItemSchema` adds `catalogSourceId: z.string().uuid().optional()`. New `packages/shared/src/schemas/content/import.ts`: `ImportPreviewSchema`, `ImportRequestSchema`, `ImportResultSchema` per contract §7 + deviations 8, 13.
2. `createRun({ topic, userId, seriesId, focusHint })`: when `seriesId` given, series must be readable+writable by the user (Phase 3 helpers) else 404/403/409; persist both columns.
3. Wire `focusHint`: add `focusHint: string | null` to `StepAgentContext` (`domain/step-agent.ts`); `AgentStepHandler` reads `run.focusHint` when building the context; `step-prompt.mapper.ts` RESEARCHER branch passes `focusHint: ctx.focusHint` to `buildResearcherPrompt`.
4. Keep `catalogSourceId` away from the LLM: in `infrastructure/pi/pi-step-agent.ts`, when `stepType === "RESEARCHER"` pass the runner an agent-facing schema `ResearchConsultationSchema.extend({ sourcesCatalogue: z.array(SourceItemSchema.omit({ catalogSourceId: true })) })` (export it from `packages/shared` as `ResearcherAgentOutputSchema`) instead of `STEP_OUTPUT_SCHEMAS.RESEARCHER`. Zod strips unknown keys, so an invented id never reaches the saved node; `DIRECT_EDIT` still validates against the full `STEP_OUTPUT_SCHEMAS.RESEARCHER`, so only Moderator edits can set it. A RESEARCHER RERUN produces a fresh catalogue without links, so links set earlier are lost by design; the import preview then asks the Moderator to decide those sources again.
5. `ImportBasisLoader` (`modules/script-workflow/application/import-basis.loader.ts`): given run + FACT_CHECKER node id, loads lineage once and returns `{ factChecker, researcher, factExtractor, storyPlanner, oralizer }` outputs parsed with their `STEP_OUTPUT_SCHEMAS`; a missing ancestor → `DomainError(409,"IMPORT_NOT_AVAILABLE")`. Basis node for preview = FACT_CHECKER `currentVersion` node if step `WAITING_FOR_HUMAN`, else `approvedVersion` node if run `COMPLETED`; neither → 409 `IMPORT_NOT_AVAILABLE`.
6. `GET /:id/import-preview`: target (`run.seriesId` → EXISTING_SERIES with `nextSortOrder`, else NEW_SERIES with `storyPlanner.seriesTitle`); `factCheck = { passed, issueCount: claimVerification.filter(s => s.status !== "VERIFIED").length }`; episodes from ORALIZER (`title` from STORY_PLANNER); sources with `origin` (`id.startsWith("custom-src-")` → MODERATOR) and candidates (trigram similarity on title + exact ISBN, limit from config); entities from `keyEntities` (deviation 13) with candidates on name/aliases.
7. `POST /:id/import` (`rateLimit("ai_import")`, `idempotency()`), `ContentImportService.import(run, userId, request)`:
   - Fast path: if an `audit_logs` row `action = 'ai_import', resource_type = 'workflow_run', resource_id = String(runId)` exists → 200 with its `changes` (the stored `ImportResult`).
   - Validate decisions (deviation 13; missing → 422 `IMPORT_DECISIONS_INCOMPLETE` + `missingItemIds`).
   - `prisma.$transaction(async (tx) => …, { timeout: import.transaction_timeout_ms })`. First statement: `` tx.$queryRaw`SELECT id FROM workflow_runs WHERE id = ${runId} FOR UPDATE` `` (serialises concurrent imports of one run), then re-check the `ai_import` audit row inside the transaction and return it (200) if present. Build `txRepo = new PrismaScriptWorkflowRepository(tx)`, `txLineage`, `txPublication`, and `new WorkflowCommandService(txRepo, queue, txLineage, txPublication)`; if FACT_CHECKER is `WAITING_FOR_HUMAN`, call `continueStep({ stepType: "FACT_CHECKER", version: basisNode.version, userId, incomingGuidance: approvalNote })` (this path never enqueues) and convert a failed `TransitionResult` to `DomainError` (404 `NOT_FOUND`, 409 `STALE_WRITE`); catch `PublicationError` thrown from it and rethrow `DomainError(409,"IMPORT_NOT_AVAILABLE", err.message)` — both roll the transaction back. If run already `COMPLETED`, require `basis` = approved node (else 409 `STALE_WRITE`) and reuse `findPublicationByApprovedVersionId`.
   - Target series: EXISTING → must still be readable+writable; NEW → `createSeriesDraft` (title from STORY_PLANNER, years/topic/period null). `appendEpisodes` with 3 episodes (`title = storyPlanner.episodes[i].episodeTitle`, THIRD_PERSON script = `oralizer.episodes[i].spokenNarration`, `scriptPublicationId`, `episodeNo = i+1`).
   - Sources: resolve each catalogue item (existing `catalogSourceId` or decision; CREATE → `title = name`, `author = authorOrOrigin`, `tier`, `url` only if http(s), merged with `overrides`); insert `episode_sources` for all 3 episodes (`locator = (locationInSource ?? "").slice(0,255)`, origin per id prefix, `sort_order` = catalogue order) with `createMany skipDuplicates`.
   - Entities: USE_EXISTING/CREATE (slug via `insertWithUniqueSlug`)/DROP; tags for all 3 episodes with status `CONFIRMED` (+`confirmed_by_id/at`) when `confirm`, else `SUGGESTED`; origin AI.
   - `workflow_runs.series_id = seriesId`; `writeAudit(tx, { action: "ai_import", resourceType: "workflow_run", resourceId: String(runId), changes: result })`.
   - Response 201 + `Location`. `GET /:id/import` → stored result or 404 `NOT_IMPORTED`.
