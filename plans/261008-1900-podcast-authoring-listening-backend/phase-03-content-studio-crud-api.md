# Phase 3 — Catalog + Series/Episode/Narration/Source/Tag CRUD (`/api/studio`, public catalog)

Module layout for all new modules (`catalog`, `content`, `media`, `listening`): `application/` services + mappers, `presentation/` route factories `createXRoute(deps)`, composition in `index.ts` (same style as `modules/script-workflow/index.ts`). New services use Prisma directly through a `DbClient` constructor parameter (no repository port: there is a single implementation and integration tests hit Postgres); writes spanning tables use `prisma.$transaction(async (tx) => …)`. Zod contracts in `packages/shared/src/schemas/content/{catalog,series,episode}.ts`, exported from `packages/shared/src/index.ts`; delete `schemas/podcast.ts`, `schemas/citation.ts`, `schemas/figure.ts` and their exports. DTO shapes are exactly contract §1–§4/§6 with the deviations above.

0. Mobile cutover for the deleted schemas (same commit): `apps/mobile/src/shared/schemas/index.ts` and `types/index.ts` drop `CitationSchema`, `EpisodeFilterQuerySchema`, `EpisodeSchema`, `FigureSchema`, `PodcastCategoryEnum`, `SeriesSchema` and their `Dto` types, keep `PeriodSchema`/`PeriodDto`, and add `HistoricalPeriodSchema`/`HistoricalPeriodDto` and `EpisodeSourceSchema`/`EpisodeSourceDto`; `apps/mobile/src/features/citations/index.ts` re-exports `EpisodeSourceDto`. Run `bun run --cwd apps/mobile check-types` (mobile has no test script).
1. Catalog (`modules/catalog`): public `GET /api/topics`, `GET /api/historical-periods` → `{ items }` (`is_active`, ordered by `sort_order`). Studio `/api/studio/sources` and `/api/studio/historical-entities` per contract §1.2–1.3:
   - Search `q`: one `$queryRaw` (built with `Prisma.sql`) returning ordered ids + total, then `findMany({ where: { id: { in } } })` re-ordered. Sources: match `immutable_unaccent(lower(title|original_title|author)) ILIKE '%'||immutable_unaccent(lower($q))||'%'` OR `isbn = normalizedIsbn`; order by `similarity(immutable_unaccent(lower(title)), immutable_unaccent(lower($q))) DESC, title`. Exclude `archived_at IS NOT NULL` unless `includeArchived=true`.
   - `/similar`: top `search.similar_candidate_limit` by `similarity(...)` using the `%` operator; register `/similar` before `/:id`.
   - Create: ISBN normalized (strip spaces/dashes, uppercase X); `createMany skipDuplicates`; `count 0` → look up by isbn → 409 `SOURCE_ISBN_TAKEN` + `existingId`. Entity slug via `insertWithUniqueSlug`.
   - Update source: creator or admin, else 404. No DELETE (archive/unarchive only).
2. Content access helper `modules/content/application/content-access.ts`:
   - `loadSeriesForRead(db, session, id)`: not found, or (role ≠ admin and `owner_id ≠ user`) → 404 `NOT_FOUND`.
   - `assertWritable(session, series, episode?)`: `deleted_at` set → 409 `CONTENT_IN_TRASH` (except restore); `admin_locked_at` on series or episode and role ≠ admin → 403 `CONTENT_LOCKED`.
   - `assertBaseUpdatedAt(row, baseUpdatedAt?)`: if provided, writes use `updateMany({ where: { id, updatedAt: baseUpdatedAt } })`; `count 0` → 409 `STALE_WRITE` with extension `current` = fresh DTO.
3. Content writer `modules/content/application/content-writer.ts` (reused by Phase 5 import): `createSeriesDraft(tx, { ownerId, title, slug?, … })` and `appendEpisodes(tx, seriesId, [{ title, slug? , thirdPersonScript?: { content, scriptPublicationId, episodeNo } }])` — sort_order continues from `max(sort_order)+1`, each episode gets its THIRD_PERSON narration row (deviation 19), `script_updated_at` set when content provided.
4. Series routes (contract §2) on `/api/studio/series`, guard `requireAuth, requireRole("moderator","admin")`:
   - List: `status=TRASH` → `deleted_at IS NOT NULL`; other statuses → `deleted_at IS NULL AND status = …`; moderators see own, admin all (+`ownerId`); `q` via trigram SQL as above.
   - Detail: includes `publishChecklist` (TOPIC, HISTORICAL_PERIOD, YEAR_RANGE, HAS_PUBLISHED_EPISODE), `episodes[].progress`, `pendingAiRuns` = `workflow_runs` with `series_id = id` and status in `PENDING|RUNNING|WAITING_FOR_HUMAN` (`awaitingStep` = `current_step` when `WAITING_FOR_HUMAN`), `cover.url` = public Cloudinary delivery URL (Phase 4 gateway; until Phase 4 lands, `cover` is `null`).
   - Create/patch: slug rules (contract §2 + `SLUG_LOCKED` when status ≠ DRAFT); cover must be an `IMAGE` asset, `READY`, uploaded by the user (admin: any) else 422 `VALIDATION_ERROR`; switching covers sets old asset `detached_at = now()` and clears the new one's, same transaction.
   - Publish: checklist fails → 422 `SERIES_NOT_PUBLISHABLE` + `checklist`. Hide/trash/restore per deviation 15. Episode order: exact non-deleted set else 422 `EPISODE_ORDER_MISMATCH`; rewrites `sort_order` 1..n and bumps `series.updatedAt` in one transaction.
   - Audit actions: `series.created|updated|published|hidden|trashed|restored|reordered`, `changes = { before, after }` of changed fields.
5. Episode routes (contract §3): create under `/api/studio/series/:seriesId/episodes` (series must be writable); workspace GET; patch; publish (checklist BASIC_INFO = title non-empty, HAS_SOURCE, THIRD_PERSON_SCRIPT non-blank, THIRD_PERSON_AUDIO with asset READY; warnings SERIES_NOT_PUBLISHED, ENTITY_TAGS_UNCONFIRMED{count}) → 422 `EPISODE_NOT_PUBLISHABLE`; hide/trash/restore (restore with series trashed → 409 `PARENT_IN_TRASH`). Audit `episode.*`.
6. Narrations (contract §4, script part; audio endpoints in Phase 4): `PUT …/narrations/:type` upserts (FIRST_PERSON create requires `narratorEntityId` of a FIGURE entity, else 422 `VALIDATION_ERROR`); clearing THIRD_PERSON script on a PUBLISHED episode → 409 `REQUIRED_FOR_PUBLISHED`; `DELETE …/narrations/FIRST_PERSON` (sets its audio asset `detached_at`); `GET …/ai-original` returns the ORALIZER `episodes[episodeNo-1].spokenNarration` found via `LineageService.getAncestryLineage(publication.approvedVersionId)` + `findAncestorNode(…, "ORALIZER")`, 404 `NOT_FOUND` when handwritten. `wordCount` = whitespace-split count; `estimatedDurationMs` = `wordCount / script.words_per_minute * 60000` rounded; `DURATION_MISMATCH` when `|audio.durationMs − estimated| / estimated > narration.duration_mismatch_ratio`.
7. Episode sources and entity tags (contract §6): duplicates detected with `createMany skipDuplicates` → `count 0` → 409 `EPISODE_SOURCE_DUPLICATE` (tags: idempotent 200 returning existing); removing the last source of a PUBLISHED episode → 409 `REQUIRED_FOR_PUBLISHED`; order endpoint exact-set rule.
8. Mount in `app.ts`: `.route("/api", publicCatalogRoute)` and `.route("/api/studio", studioRoute)` where `studioRoute` composes sources, historical-entities, series, episodes (and media in Phase 4).
