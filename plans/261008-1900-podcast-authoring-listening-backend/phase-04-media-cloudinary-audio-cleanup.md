# Phase 4 — Media (Cloudinary), audio attach, cover URLs, cleanup jobs

1. In `apps/api`: `bun add --exact cloudinary` (official SDK; signing, Admin API, signed delivery URLs — not worth hand-rolling).
2. `modules/media/infrastructure/cloudinary.gateway.ts` implementing interface `MediaStorageGateway` (`modules/media/application/media-storage.ts`):
   - `signUpload({ publicId, kind, allowedFormats })` → `{ url, fields, expiresAt }` using `cloudinary.utils.api_sign_request({ public_id, timestamp, type, allowed_formats: formats.join(",") }, secret)`; `type` = `authenticated` for AUDIO, `upload` for IMAGE; `expiresAt = timestamp + media.upload_ticket_ttl_seconds`.
   - `fetchResource(publicId, kind)` → `{ version, format, bytes, durationMs | null } | null` (Admin API `cloudinary.api.resource` with `resource_type` video/image, matching `type`; HTTP 404 → `null`; timeout `CLOUDINARY_TIMEOUT_MS`; any other failure throws `MediaProviderError`).
   - `destroy(publicId, kind)` → `"deleted" | "not_found"` (`cloudinary.uploader.destroy`, `invalidate: true`), failures throw `MediaProviderError`.
   - `deliveryUrl(asset)`: AUDIO → `cloudinary.url(publicId, { resource_type: "video", type: "authenticated", sign_url: true, secure: true, version, format })`; IMAGE → same without `sign_url`, `type: "upload"`.
   - Missing Cloudinary env → every method throws `MediaProviderError("Cloudinary is not configured")`. `MediaProviderError` is mapped by the media service to `DomainError(503,"MEDIA_PROVIDER_UNAVAILABLE")`.
   - MIME for playback DTO derived from format: `mp3→audio/mpeg`, `m4a→audio/mp4`, `ogg→audio/ogg` (`modules/media/application/mime.ts`).
3. `MediaService` + routes `/api/studio/media-assets` (contract §5 with deviation 11): create (validates `mimeType`/`sizeBytes` against config → 422 `MEDIA_TYPE_NOT_ALLOWED`/`MEDIA_TOO_LARGE`; inserts `PENDING` row with `public_id = ${CLOUDINARY_FOLDER}/${kind === "AUDIO" ? "audio" : "image"}/${assetId}`); verify (owner or admin else 404; READY → 200 idempotent; `fetchResource` null → 409 `MEDIA_NOT_UPLOADED`; format not allowed, bytes over limit, or AUDIO without positive duration → `destroy` + status `DELETED` + 422 `MEDIA_INVALID`; else READY with `version`, `format`, `size_bytes`, `duration_ms = round(duration*1000)`, `verified_at`); GET. Factory `createMediaRoute({ service })` so tests inject a fake gateway.
4. Audio attach/detach (contract §4 `PUT|DELETE …/narrations/:type/audio`): asset checks (AUDIO, READY, uploader = user or admin) → else 422 `VALIDATION_ERROR`; asset already referenced by another narration → 409 `ASSET_IN_USE`; replacing audio of a PUBLISHED episode without `confirmReplacePublished: true` → 409 `REPLACE_CONFIRMATION_REQUIRED`; removing THIRD_PERSON audio of a PUBLISHED episode → 409 `REQUIRED_FOR_PUBLISHED`. One transaction: set FK + `audio_provider` + `audio_attached_at`, old asset `detached_at = now()`, new asset `detached_at = null`, audit `narration.audio_attached|audio_replaced|audio_removed`. `audio.previewUrl` in NarrationDto = signed delivery URL. Fill `cover.url` in Series DTOs.
5. Maintenance jobs, new `apps/api/src/core/jobs/maintenance-jobs.ts`: own `PgBoss` instance (same `DATABASE_URL`); `startMaintenanceJobs(connectionString, handlers)` creates queues `maintenance.media-cleanup` (cron `MEDIA_CLEANUP_CRON = "*/30 * * * *"`), `maintenance.idempotency-purge` (`"0 * * * *"`), `maintenance.rate-limit-purge` (`"15 * * * *"`) via `boss.createQueue` + `boss.schedule` + `boss.work`; `stopMaintenanceJobs()`. Wire both into `apps/api/src/index.ts` next to the script-workflow runtime start/stop (start failure is fatal like the workflow runtime).
   - Media cleanup: select up to `media.cleanup_batch_size` assets with `status <> 'DELETED'`, not referenced by `episode_narrations.audio_asset_id` or `series.cover_image_asset_id` (only these two count; `listening_progress.audio_asset_id` never counts), `COALESCE(detached_at, created_at) < now() - grace`; `destroy` each (`not_found` counts as done) → `status DELETED, deleted_at now()`; provider failure → `logger.warn` with asset id and continue.
   - Idempotency purge: delete `expires_at < now()`. Rate-limit purge: delete `window_start < now() - interval '1 day'`.
