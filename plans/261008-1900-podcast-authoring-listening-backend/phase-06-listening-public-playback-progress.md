# Phase 6 — Listening (public browse, playback, progress, history, XP/missions)

1. Contracts `packages/shared/src/schemas/listening/*.ts` per contract §8 + deviations 9, 16–18: `PublicSeriesListQuerySchema`, `PublicSeriesListItemSchema`, `PublicSeriesDetailSchema`, `PublicEpisodeDetailSchema`, `PublicEpisodeSourceSchema`, `PlaybackSchema`, `ListeningProgressSchema`, `UpdateListeningProgressRequestSchema` (`assetId` uuid, `positionMs` int ≥0, `playedBitmap` base64 string ≤ 4096 chars), `ListeningProgressUpdateResultSchema`, `ListeningHistoryQuerySchema`, `ListeningHistoryItemSchema`, plus `Dto` types. Mobile: add re-exports of `PublicSeriesListItemSchema`, `PublicEpisodeDetailSchema` (+`Dto`) to `apps/mobile/src/shared/{schemas,types}/index.ts` and point `features/citations/index.ts` at `PublicEpisodeSourceDto`.
2. Public routes (`attachSession`): `GET /api/series` (public = Series PUBLISHED and `deleted_at IS NULL`; year overlap `start_year <= toYear AND end_year >= fromYear`; `q` trigram), `GET /api/series/:slug` (public episodes ordered by `sort_order`, `viewer` per deviation 17), `GET /api/episodes/:slug` (contract §8.1; episode public = episode PUBLISHED + series PUBLISHED + both not deleted; entities CONFIRMED only; `hasQuiz` = quiz row exists; `available` = narration has READY audio). Non-public → 404 `NOT_FOUND`.
3. `GET /api/narrations/:narrationId/playback` (`requireAuth`): narration must be public and have audio else 404 `CONTENT_UNAVAILABLE`; response per contract §8.2; stored progress for another asset is returned reset (position 0, empty bitmap, `completedAt` kept); `Cache-Control: private, no-store`; `sync = { intervalMs, completionThreshold }` from config.
4. Progress (`requireAuth`, PUT also `rateLimit("listening_progress")`), `ListeningService.updateProgress`, one transaction:
   - Narration public with audio else 404 `CONTENT_UNAVAILABLE`; `assetId ≠ current` → 409 `AUDIO_CHANGED` + `current { assetId, url, durationMs }`; `positionMs > durationMs` or decoded bitmap longer than deviation-18 length → 422 `PROGRESS_INVALID` (shorter → zero-padded; bits past the last second masked).
   - Ensure row (`createMany skipDuplicates`, empty bitmap, `audio_asset_id = current`, `episode_id` denormalized), then lock it with `$queryRaw\`SELECT … FROM listening_progress WHERE user_id = … AND narration_id = … FOR UPDATE\``. Row on an old asset → reset bitmap/position/`played_seconds`, set new asset, keep `completed_at`.
   - Anti-spoof: `newBits` = bits set in request and not stored, ascending; `allowed = ceil(elapsedSec * maxRate) + ceil(syncIntervalSec * maxRate * toleranceIntervals)` with `elapsedSec = (now − last_listened_at)/1000` (fresh row: 0). Excess → keep the first `allowed` new bits and `logger.warn({ requestId, userId, narrationId, requested, allowed })`.
   - OR, `played_seconds = popcount`, `position_ms`, `last_listened_at = now`. First time `played_seconds >= ceil(totalSeconds * completion_ratio)` → `completed_at = now`; `xp_awards` `createMany skipDuplicates` (`EPISODE_COMPLETION`, episode id, `xp.episode_completion`), `count 1` → `users.total_xp += amount`; weekly missions: current week Monday computed in `Asia/Ho_Chi_Minh` (named constant `VN_TIMEZONE`), missions with `activity_type = COMPLETE_EPISODE`, that `week_start_date`, `activated_at <= now`; per mission upsert `user_weekly_missions`, `user_weekly_mission_items` `createMany skipDuplicates` (content id = episode id; `count 0` → skip), increment `progress_count`, reaching `target_count` with `completed_at` null → set it, `xp_awards(WEEKLY_MISSION, weekly_mission_id)` + `total_xp`.
   - Response per contract §8.3; `completion` non-null only on the request that set `completed_at`.
   - `GET /api/me/listening-progress/:narrationId` per deviation 16.
5. History `GET /api/me/listening-history`: raw SQL grouping `listening_progress` by `episode_id` (latest row via `DISTINCT ON (episode_id) … ORDER BY episode_id, last_listened_at DESC`, `percent` = max over the episode's narrations using `media_assets.duration_ms`, `isCompleted` = any `completed_at`), ordered by `lastListenedAt DESC`, paginated; `status` filter on `isCompleted`; non-public episodes kept with `episode.available: false`.
6. Mount: `.route("/api", publicListeningRoute)` (series/episodes/narrations) and `.route("/api/me", meListeningRoute)` beside the existing `currentUserRoute`.
